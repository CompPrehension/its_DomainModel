# Loqi Syntax for Sublime Text

This package adds syntax highlighting for `.loqi` and `.tpg` files.

## Install locally

Copy or symlink the `Loqi` directory into Sublime Text `Packages`.

On Windows, the target is usually:

```text
%APPDATA%\Sublime Text\Packages\Loqi
```

After that, choose `View > Syntax > Loqi` or open a `.loqi` / `.tpg` file.
